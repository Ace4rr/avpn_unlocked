# avpn_unlocked 👅

## Description
Browser shark vpn extension (reworked amneziavpn's ext) 

## Installation

### For Google Chrome, Microsoft Edge, Brave, and other Chromium-based browsers:
1. Download or clone this repository to your local machine:
   ```bash
   git clone <https://github.com/Ace4rr/avpn_unlocked>
   ```
2. Open your browser and navigate to the extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
3. Enable **Developer mode** (usually a toggle switch in the top right or bottom left corner).
4. Click on **Load unpacked** (or similar button).
5. Select the folder containing the extension files (where `manifest.json` is located).

### For Mozilla Firefox:
1. Download or clone this repository to your local machine.
2. Open Firefox and navigate to `about:debugging#/runtime/this-firefox`.
3. Click on the **Load Temporary Add-on...** button.
4. Select the `manifest.json` file (or any other file) inside the extension's folder.
*Note: Temporary add-ons are removed when Firefox restarts. For permanent installation, you will need to sign the extension through Mozilla Add-ons.*

## Usage
1. Click the extension icon in your browser's toolbar to open the popup.
2. Use the interface to configure and connect to your preferred network settings.
3. Click the gear icon to access additional network configurations.
